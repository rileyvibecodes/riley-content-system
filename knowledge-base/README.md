# Knowledge Base

This directory contains reference materials that inform the content generation system.

## Required Files

### 1. Business.txt
Your brain dump of business ideas, philosophy, and insights. Copy your existing Business.txt here.

### 2. WBYO-VSL.txt
Your sales letter for Will Build Your Offer. Used for voice reference and offer positioning.

### 3. Master-Positioning.md
Your core positioning document. Who you help, what you do, how you're different.

### 4. swipe-file/
Directory containing your best-performing tweets and content for voice matching.

## Optional Files

### 5. Previous Field Guides
Examples of past breakdowns in `examples/` subdirectory.

### 6. Agency Audits
Case study examples and audit outputs.

## How Files Are Used

1. **Voice Matching**: Swipe file content is used to train the voice checker
2. **Topic Ideas**: Business.txt provides raw material for topic selection
3. **Positioning**: VSL and positioning docs ensure content aligns with your offer
4. **Examples**: Past guides inform structure and style

## Adding New Content

Simply add files to this directory. The n8n workflow will automatically incorporate them.

For best results:
- Use plain text (.txt) or markdown (.md)
- Keep files focused on single topics
- Update regularly with new insights
